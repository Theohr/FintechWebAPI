# FintechWebAPI
Created a real time Fintech Web API using .NET Core, C#, Redis, EF/ADO.NET, SIgnalR that:
1) Executes trades
2) Cancels trades
3) Changes traders preferences
4) Prints trader's trading history
5) Tracks traders trading activity
6) Adjusts Trader's balance according to trades
7) Checks suspicious activity
8) Handle massive amount of trades per second
